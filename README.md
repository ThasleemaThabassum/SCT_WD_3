# SCT_WD_3 - Quiz Game Application

## 🏢 SkillCraft Technology | Web Development Internship | Task 3

An interactive multiple-choice quiz game built as part of my Web Development Internship at SkillCraft Technology.

## ✨ Features
- 3 question types: Multiple Choice, True/False, Fill in the Blank
- 15 second countdown timer per question
- Instant correct/wrong feedback with color highlights
- Skip option for any question
- Final score screen with correct, wrong and skipped breakdown
- Motivational result messages and Play Again option

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
